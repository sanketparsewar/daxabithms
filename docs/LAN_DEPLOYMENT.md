# LAN Deployment (Retired)

LAN browser access and multi-device client mode are no longer part of the supported desktop product. The desktop packages bind the frontend and API to loopback, and the Linux package publishes its UI on `127.0.0.1` only.

Use the local desktop app on Windows or Ubuntu/Debian. The frontend and Node.js backend remain separate code/build packages for development and custom deployment work, but this repository no longer provides a supported LAN server setup.
